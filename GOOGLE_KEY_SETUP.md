# Google OAuth Admin Panel Kurulumu

- Google OAuth üzerinden client id ve client secret key almanız gerekiyor.

- İlk önce /admin üzerinden Sites oluşturun.

- Domaininizi girip kaydedin (eğer localse localhost:8000 yazabilirsiniz).

- Ardından /admin üzerinden social applications'a girin.

- İsim olarak Google OAuth yazabilirsiniz.

- Client ID ve Client Secret'ı ilgili kutucuklara yapıştırın.

- Aşağıdan sites kısmından alan adlarını ekleyin.
